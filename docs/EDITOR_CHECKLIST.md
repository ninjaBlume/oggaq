# Editör kontrol listesi — aynı soru metni, çelişen doğru cevap

Aynı metni taşıyan sorulardan birinin doğru cevabı, diğerinde yanlış şık olarak geçiyor. Hangisinin doğru olduğu kaynak sınav kitapçığından teyit edilmelidir.


## 1. Aşağıdakilerden hangisi silah bakım ve temizliği türlerinden değildir?

- doğru: **Günlük bakım** — şıklar: Günlük bakım / Haftalık bakım / Yıllık bakım / Atış öncesi bakım / Atış sonrası bakım
- doğru: **Aylık Bakım** — şıklar: Günlük bakım / Haftalık bakım / Atış öncesi bakım / Atış sonrası bakım / Aylık Bakım

## 2. Aşağıdakilerden hangisi silahı sökmeye başlamadan önce yapılması gereken ilk işlemdir?

- doğru: **Silah ölü noktaya tutulur** — şıklar: Sürgü çekilerek fişek yatağı kontrol edilir / Şarjör çıkartılır / Silah ölü noktaya tutulur / Sürgü çekilerek namlu parmakla da kontrol edilir / Sürgü geriye çekilerek namlu gözle kontrol edilir
- doğru: **Şarjör çıkartılır** — şıklar: Sürgü çekilerek fişek yatağı kontrol edilir / Şarjör çıkartılır / Silah ölü noktaya tutularak horoz düşürülür / Sürgü çekilerek namlu parmakla da kontrol edilir / Sürgü geriye çekilerek namlu gözle kontrol edilir

## 3. Aşağıdakilerden hangisi silah temizliğinde gerekli malzemelerden değildir?

- doğru: **Harbi** — şıklar: Harbi / Süngü / Temizleyici yağ / Kıl fırça / Temizlik bezi
- doğru: **Tornavida** — şıklar: Koruyucu yağ / Namlu için özel yağ / Temizleyici yağ / Harbi / Tornavida

## 4. Aşağıdakilerden hangisi Özel Güvenlik Denetleme Başkanlığı tarafından yapılan sınavlardan değildir?

- doğru: **Özel Güvenlik Temel ve Yenileme Eğitim Sınavı** — şıklar: Özel Güvenlik Temel ve Yenileme Eğitim Sınavı / Bomba İmha Uzmanı Sınavı / Silah Tamir Yeri Açma Sınavı / Ateşleyici Yeterlilik Belge Sınavı / Görev Köpeği ve İdarecisi Sınavı
- doğru: **Ehliyet Sınavı** — şıklar: Özel Güvenlik Temel ve Yenileme Eğitim Sınavı / Ehliyet Sınavı / Silah Tamir Yeri Açma Sınavı / Ateşleyici Yeterlilik Belgesi Sınavı / Görev Köpeği ve İdarecisi Sınavı
- doğru: **Ehliyet Sınavı** — şıklar: Ehliyet Sınavı / Özel Güvenlik Temel ve Yenileme Eğitim Sınavı / Silah Tamir Yeri Açma Sınavı / Ateşleyici Yeterlilik Belgesi Sınavı / Görev Köpeği ve İdarecisi Sınavı

## 5. Gez ve arpacık yarı otomatik tabancaların hangi ana parçası üzerinde bulunur?

- doğru: **Harbi** — şıklar: Kabza / Namlu / Sürgü / Harbi / Horoz
- doğru: **Sürgü** — şıklar: Gövde / Namlu / Şarjör / Sürgü / İğne mekanizması

## 6. Aşağıdakilerden hangisi tabancanın başlıca parçalarından değildir?

- doğru: **Tırnak** — şıklar: Namlu / Tırnak / Yerine getiren yay ve mili / Çerçeve ( Gövde) / Hazne
- doğru: **Namlu** — şıklar: Namlu / Sürgü / Yerine getiren yay ve mili / Çerçeve (Gövde) / Kabza
